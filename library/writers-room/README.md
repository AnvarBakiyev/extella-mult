# Сценарная комната: войлочная сатира

Библиотека для коротких (35–60 с) серий с войлочными куклами для взрослых: телеинтервью, документалки, реклама и ещё 22 телевизионных жанра, сыгранные всерьёз. Абсурд в содержании, жанр соблюдается идеально, в конце — неожиданная последняя реплика. Продолжение линии серии про лосося (интервью с лососем → реклама крема на молоках → лосось берёт интервью у человека).

| файл | что внутри |
|---|---|
| `formats.md` | 25 форматов: такты с секундами, кадры, движения камеры, где поворот |
| `cast.md` | все персонажи (`ch_…`) с брифом для куклы и кадрирования |
| `places.md` | все места (`pl_…`) с брифом для декорации |
| `episodes/E001.md … E150.md` | 150 готовых сценариев, по 6 на формат: E001–E006 = F01, E007–E012 = F02 и т. д. |
| `index.csv` | сводка: id, формат, название, персонажи, места, длительность, лучшая реплика |
| `tools/check.py` | проверка сценариев и сборка `index.csv` (`python3 tools/check.py --index`) |

## Правила юмора

- Сухо, по-взрослому, абсурдно. Темы: работа, деньги, технологии, бюрократия, здоровье, семья, города, природа, ИИ.
- Играем всерьёз: никто не подмигивает зрителю, музыка не подсказывает шутку.
- Нельзя: реальные люди, политики, реальные марки, названия стран и городов, религия, национальные стереотипы как шутка, жестокость к детям. Дети в кадре умнее взрослых, смешна система, а не ребёнок.
- Каждая реплика короткая: около 2 слов в секунду. Проверка ругается, если в строке больше 2,5 слова на секунду.
- Поворот — в последних 3–6 секундах. Последняя реплика не объясняет шутку.

## Шаблон сценария

```
# E000. Название

- **Формат:** F01 Интервью
- **Длительность:** 45 с
- **Логлайн:** одно предложение.
- **Персонажи:** ch_dina, ch_barrel
- **Места:** pl_tv_studio
- **Лучшая реплика:** «…»

| с | кадр | кто | реплика | камера | звук | музыка |
|---|---|---|---|---|---|---|
| 0–4 | 2Ш | Дина | … | медленный наезд | — | заставка |

**Последняя реплика:** Кто: «…»
```

Время в таблице идёт без разрывов от 0 до длительности. Если в такте молчат, в колонке «реплика» ставится «—», а действие пишется в «кадр» или «звук».
