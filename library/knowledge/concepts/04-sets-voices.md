# PUPPET: sets and voices
tags: sets, cast, places, voices, who, ch_, pl_
A set is one camera on one character or place. Writers-room names: ch_<code> is a character set with a talking mouth (ch_dina, ch_salmon, ch_piggybank). pl_<code> is a place set without a mouth (pl_tv_studio, pl_court). ad_cream is the beauty-commercial pack shot.
say needs a set with a mouth: say ch_dina "...". A pl_ set never talks; put a voice over it.
Each ch_ set has its own voice; do not write who= on say unless asked.
Who is on screen talks with say on THEIR set. Someone heard but not shown: voice "..." who=<voice>.
Voices: narrator, journalist, lady, calm, fairy, deep, ad, salmon, odessa, gogi.
voice without a tag or who= is the deep narrator. "[ad] ..." is the bright commercial voice.
Never pick an accent voice (odessa, gogi) to match a character's nationality or origin.
Use only set names the catalog returns. Unknown set = check error; search the catalog, do not invent.
